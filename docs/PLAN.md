# แผนพัฒนา Progressive Web App: ติดตามสถานการณ์น้ำท่วม กทม. และปริมณฑล

> สถานะ: v0.3 — ปรับตามข้อสรุปกับเจ้าของโครงการ และเริ่ม MVP แล้ว (ดู `README.md`)
> รายการที่มีเครื่องหมาย **[ต้องยืนยัน]** คือสิ่งที่ต้องตรวจสอบกับแหล่งข้อมูลจริง

## 1. ข้อสรุปจากเจ้าของโครงการ

| หัวข้อ | ข้อสรุป | ผลต่อการออกแบบ |
|---|---|---|
| กลุ่มผู้ใช้ | ประชาชนทั่วไป | ภาษาไทยเป็นหลัก, ใช้งานง่ายบนมือถือ, ต้องมีข้อความว่า "ไม่ใช่ประกาศทางการ" |
| ข้อตกลงใช้ข้อมูลกับหน่วยงาน | ยังไม่มี | ใช้เฉพาะ API/ข้อมูลสาธารณะ, ไม่ scrape เว็บภาครัฐ |
| CCTV | ลิงก์ไปดูที่ระบบกล้องของ กทม. ได้ | **ไม่ต้องมี CCTV proxy / สตรีมวิดีโอ** — แสดงเป็นลิงก์ออกไปยังเว็บของหน่วยงาน |
| ประตูระบายน้ำ | ดูสถานะอย่างเดียว | ไม่มีฟังก์ชันสั่งการ, อ่านอย่างเดียว |
| งบประมาณ | ทำฟรีก่อน | ไม่มีฐานข้อมูล/Redis ใน MVP, ใช้ cache ในหน่วยความจำ, โฮสต์บนบริการ free tier |
| ภาษา backend | Node.js | Node.js + TypeScript + Hono |

## 2. แหล่งข้อมูล

### 2.1 ดึงข้อมูลเข้าแอป

| กลุ่มข้อมูล | แหล่งข้อมูล | สถานะ | หมายเหตุ |
|---|---|---|---|
| ระดับน้ำ (คลอง/แม่น้ำ) ใน 6 จังหวัด | ThaiWater public API `waterlevel_load` | ✅ | **[ต้องยืนยัน]** โครงสร้าง JSON — adapter อ่านค่าแบบยืดหยุ่น |
| สถานีต้นน้ำสำคัญ (น้ำเหนือ) | ThaiWater `waterlevel_load` (ชุดเดียวกัน) กรองตามรหัสสถานี C.2, C.13, C.7A, C.35 | ✅ | ใช้ `tele_station_oldcode` (C.29A บางไทร ไม่มีในชุดข้อมูลนี้) |
| ฝนสะสม 24 ชม. | ThaiWater public API `rain_24h` | ✅ | **[ต้องยืนยัน]** |
| พยากรณ์น้ำล้นตลิ่งล่วงหน้า | Google Flood Forecasting API (`floodStatus:searchLatestFloodStatusByArea`) | ✅ พร้อมใช้เมื่อมี API key | ฟรี แต่ต้องสมัคร waitlist และรออนุมัติ |
| สถานะประตูระบายน้ำ | ThaiWater / กรมชลประทาน / สำนักการระบายน้ำ กทม. | ⚠️ ตั้งค่า URL ได้ | **[ต้องยืนยัน]** ยังไม่พบ endpoint สาธารณะ |

### 2.2 ลิงก์ออกไปยังเครื่องมือของหน่วยงาน (ไม่มี API สาธารณะ หรือเหมาะให้ผู้ใช้ดูที่ต้นทาง)

| เครื่องมือ | ใช้ทำอะไร | พื้นที่ |
|---|---|---|
| ThaiWater One Map (thaiwater.net/new4all) | ปริมาณน้ำในเขื่อน อัตราการระบาย ระดับน้ำสถานีสำคัญ — ประเมินเวลาน้ำถึงท้ายน้ำ | ทั่วประเทศ |
| BMA Traffic (cpudapp.bangkok.go.th/bmatraffic) | กล้อง CCTV ถนนก่อนเดินทาง | กทม. |
| กรมทางหลวง HDMS (hdms.doh.go.th/dashboard) | CCTV และพิกัดน้ำท่วมบนทางหลวง | ทั่วประเทศ |
| Longdo Traffic (traffic.longdo.com) | รวมกล้องจราจรหลายหน่วยงาน | กทม. และปริมณฑล |
| Google Flood Hub (sites.research.google/floods) | พยากรณ์น้ำล้นตลิ่งหลายวันล่วงหน้า | ทั่วประเทศ |
| ระบบตรวจวัดน้ำท่วมถนน กทม. (weather.bangkok.go.th/flood) | ระดับน้ำท่วมขังบนถนนจากเซนเซอร์ | กทม. |
| สำนักการระบายน้ำ กทม., GISTDA | สถานการณ์น้ำในคลอง, แผนที่น้ำท่วมจากดาวเทียม | กทม. / ทั่วประเทศ |

### 2.3 ต่อยอดได้ในอนาคต (ต้องขอความร่วมมือ)

- **ระบบตรวจวัดน้ำท่วมถนน กทม.**: หากได้รับอนุญาตให้ใช้ข้อมูลเซนเซอร์ จะแสดงจุดน้ำท่วมถนนบนแผนที่ได้โดยตรง — มีประโยชน์ที่สุดสำหรับคน กทม.
- **กรมทางหลวง HDMS**: พิกัดจุดน้ำท่วมบนทางหลวงในปริมณฑล
- **ThaiWater ข้อมูลเขื่อน**: ปริมาณน้ำและอัตราการระบายของเขื่อนเจ้าพระยา / ป่าสัก

## 3. สถาปัตยกรรม (ฉบับฟรี)

```
ผู้ใช้ (มือถือ/เดสก์ท็อป)
  │
  ▼
PWA (Vite + TypeScript + Leaflet + vite-plugin-pwa)      ← โฮสต์ฟรี: GitHub Pages / Cloudflare Pages
  - แผนที่ฐาน OpenFreeMap (vector, ฟรี ไม่ต้องใช้ key) ผ่าน Leaflet + MapLibre สำรองด้วย OpenStreetMap
  - ชั้นข้อมูล ระดับน้ำ / ฝน / ประตูระบายน้ำ / พยากรณ์ Google
  - Service Worker: cache แอป + ข้อมูลล่าสุด (ใช้ได้ตอนออฟไลน์)
  - แท็บ "กล้อง CCTV" = ลิงก์ไปเว็บของหน่วยงาน
  │  REST (JSON)
  ▼
API (Node.js + Hono)                                     ← โฮสต์ฟรี: Render / Koyeb
  - /api/water-level  /api/key-stations  /api/rain  /api/floodgates
  - /api/flood-forecast (Google)  /api/links  /api/health
  - cache ในหน่วยความจำ 5 นาที, ส่งข้อมูลเก่า (สูงสุด 6 ชม.) พร้อมป้าย stale เมื่อต้นทางล่ม
  - กรองเฉพาะ 6 จังหวัด (กทม., นนทบุรี, ปทุมธานี, สมุทรปราการ, สมุทรสาคร, นครปฐม)
  │
  ▼
ThaiWater public API + Google Flood Forecasting API
```

เหตุผลที่ยังต้องมี API กลาง แม้จะอยากประหยัด: ลดจำนวนคำขอไปยังระบบของหน่วยงาน (ผู้ใช้หลายพันคนใช้ cache ชุดเดียวกัน),
แก้ปัญหา CORS, และแปลงข้อมูลเป็นรูปแบบเดียวกันก่อนส่งให้หน้าเว็บ

## 5. ข้อจำกัดของเวอร์ชันฟรี

- บริการฟรีบางแห่ง (เช่น Render) จะหยุดเซิร์ฟเวอร์เมื่อไม่มีการใช้งาน คำขอแรกอาจช้า 30–60 วินาที
- cache อยู่ในหน่วยความจำ เซิร์ฟเวอร์รีสตาร์ทแล้วต้องดึงใหม่
- ไม่มีข้อมูลย้อนหลัง/กราฟ จนกว่าจะเพิ่มฐานข้อมูล (ทางเลือกฟรี: Supabase / Neon free tier)
- แผนที่ฐานใช้ OpenFreeMap (ฟรี ไม่จำกัดจำนวนการใช้งาน แต่ไม่มี SLA) หากโหลดไม่ได้หรือเครื่องไม่รองรับ WebGL จะสลับไปใช้ OpenStreetMap ให้อัตโนมัติ
- ชื่อสถานที่บนแผนที่ vector แสดงตามข้อมูล OpenStreetMap — ควรตรวจการแสดงผลภาษาไทยบนอุปกรณ์จริงหลัง deploy
- Web Push บน iOS ใช้ได้เมื่อผู้ใช้ "เพิ่มไปยังหน้าจอโฮม" เท่านั้น

## 6. เกณฑ์สถานะ (ปรับได้ใน `packages/shared/src/index.ts`)

- ระดับน้ำ (% ของระดับตลิ่ง): <70 ปกติ, 70–90 เฝ้าระวัง, 90–100 เตือนภัย, >100 วิกฤต
- ฝนสะสม 24 ชม.: ≤10 มม. ปกติ, 10–35 เฝ้าระวัง, 35–90 เตือนภัย (ฝนหนัก), >90 วิกฤต (ฝนหนักมาก)
